Chinese Github

将 GitHub 界面翻译为中文的浏览器扩展 / 用户脚本

v0.2.3

项目简介

内置 581 条常用词条，覆盖 GitHub 导航、仓库页、议题与拉取请求、Copilot 设置、通知中心、个人主页等常用界面。代码块、Release 正文、评论等用户创作内容保持原文，不会被误翻译。

安装方法

格式适用平台方法
.user.js Stay（iOS / macOS） 在 Stay 扩展内添加脚本，粘贴安装链接
.zip 电脑端 Edge 解压后，在扩展页面右下角打开开发者模式，再导入解压缩的扩展
.crx 移动端理论可安装 拖入扩展页面安装

.crx 和 .js 打包文件由 AI 编写，如有 BUG 请见谅！

Stay 自动更新安装链接

在 Stay 中选择「从链接添加脚本」，粘贴以下地址，之后可直接在 Stay 内检查更新：

https://raw.githubusercontent.com/zhaotang5/Chinese-Github/main/stay/Chinese-Github.user.js
